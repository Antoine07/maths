### QCM - Introduction à la gestion de projet

1. Les "acteurs d'un projet" font référence à :  
A. Uniquement au client  
B. Uniquement au développeur  
C. Les différentes personnes impliquées dans le projet  
D. Les logiciels utilisés  
**Réponse : C. Les différentes personnes impliquées dans le projet**

2. Connaître les missions du chef de projet sert surtout à :  
A. Clarifier ses responsabilités  
B. Éviter toute communication  
C. Supprimer les délais  
D. Remplacer les équipes  
**Réponse : A. Clarifier ses responsabilités**

3. Comprendre les phases d'un projet permet de :  
A. Suivre une logique de progression  
B. Travailler sans méthode  
C. Ignorer les objectifs  
D. Éviter la coordination  
**Réponse : A. Suivre une logique de progression**

4. Ce cours est une introduction, donc il vise d'abord à :  
A. Fournir des bases essentielles avant l'approfondissement  
B. Former des experts en finance  
C. Déployer un produit final  
D. Écrire du code avancé  
**Réponse : A. Fournir des bases essentielles avant l'approfondissement**

5. Quel est le premier objectif du cours ?  
A. Créer une entreprise  
B. Acquérir les notions de base de gestion de projet  
C. Apprendre à coder  
D. Faire du marketing  
**Réponse : B. Acquérir les notions de base de gestion de projet**

6. Le cours vise aussi à :  
A. Identifier les rôles des différents acteurs d'un projet  
B. Remplacer le chef de projet  
C. Supprimer les réunions  
D. Éviter la planification  
**Réponse : A. Identifier les rôles des différents acteurs d'un projet**

7. Parmi les objectifs, on trouve :  
A. Connaître les différentes missions d'un chef de projet  
B. Apprendre la comptabilité avancée  
C. Concevoir un site web  
D. Gérer uniquement le budget  
**Réponse : A. Connaître les différentes missions d'un chef de projet**

8. Le cours demande de comprendre :  
A. Les outils de design uniquement  
B. Les différentes phases d'un projet  
C. La programmation orientée objet  
D. Les réseaux sociaux  
**Réponse : B. Les différentes phases d'un projet**

9. Le dernier objectif mentionné est de :  
A. Connaître quelques méthodologies de gestion de projet  
B. Passer une certification Scrum  
C. Recruter une équipe  
D. Écrire un cahier des charges complet  
**Réponse : A. Connaître quelques méthodologies de gestion de projet**
